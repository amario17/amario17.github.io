They were born from recurring needs in my daily work, such as analyzing trials environment by environment, preparing data for genotype by environment models, building environmental covariates and choosing representative test sites. How it works

For each level of the environment factor, get_weights_blue() fits an independent mixed model in ASReml. The response is modeled with a fixed genotype effect plus a random block effect (RCBD design), or a random replicate and incomplete block within replicate effect (lattice design). From each model it extracts the genotype BLUEs together with their full variance-covariance matrix, and computes a weight for every genotype as the diagonal of the inverse of that matrix:

W = diag( solve(vcov) )

where vcov is the variance-covariance matrix of the predicted genotype means in that environment. These weights, together with the environment's residual variance (sigma2), are exactly what the second stage of a weighted two-stage GxE analysis needs, such as factor analytic or GIS-FA models. As a result, BLUEs estimated with less precision receive less weight.

Smith, Cullis & Thompson (2001), Biometrics 57(4), 1138–1147 · Smith, Cullis & Gilmour (2001), Aust. N.Z. J. Stat. 43(2), 129–145 · Möhring & Piepho (2009), Crop Science 49(6), 1977–1988.

How it works

For each environment, single_analysis() fits two mixed models in ASReml, one with genotype as a random effect and a null model without it, and compares them with a likelihood-ratio test (LRT) to check whether the genotype effect is significant. From the same models it extracts the genetic and residual variance components, Cullis heritability (based on the average standard error of a difference, avsed), broad-sense heritability and the residual coefficient of variation (CV). Environments where the genotype effect is not significant (p ≥ alpha) are dropped, and the remaining ones are renamed sequentially (E01, E02, ...). The output is ready for the next multi-environment models, such as factor analytic or GIS-FA, which expect clean, sequential environment labels.

Cullis, Smith & Coombes (2006), J. Agric. Biol. Environ. Stat. 11(4), 381–393 · Piepho & Möhring (2007), Genetics 177(3), 1881–1888.

How it works

rfsi_envcov() wraps Random Forest Spatial Interpolation (RFSI) in a complete workflow, using the rfsi() and pred.rfsi() functions from the meteo package. The problem it solves: climate covariates are only available on a coarse grid (e.g. NASA POWER, ~50 km), while soil covariates come from a much finer grid (e.g. SoilGrids, ~1 km), and a genomic prediction model needs both on the same grid. Unlike a plain random forest, RFSI does not use coordinates alone as predictors. For every target point it builds features from the observed values at its n nearest neighbors and the distances to them, so the model captures spatial autocorrelation directly. The idea is similar to kriging, but without assuming a parametric variogram. For each climate variable, the function first tunes the number of neighbors and trees by leave-one-out cross-validation, then refits on all training points and predicts onto the fine grid. It returns a single table with the original soil variables and the interpolated climate variables.

Sekulić, Kilibarda, Heuvelink, Nikolić & Bajat (2020), Remote Sensing 12(10), 1687.

How it works

get_envcov() builds the environmental covariate matrix (W) with weather, soil or both for any set of geographic points, covering two scenarios. For evaluated environments (real trials), you pass points with each site's actual planting and harvest dates, and weather is downloaded for the real cycle. For unevaluated environments (a prediction grid), there are no real dates, so you define a typical planting window, the cycle length and a range of years to average over. Weather comes from NASA POWER through EnvRtype::get_weather(), with ecophysiological variables (GDD, FRUE, VPD, etc.) derived by EnvRtype::processWTH() from the crop's cardinal temperatures. Soil data come from SoilGrids rasters downloaded beforehand and sampled at each point with terra::extract(). Batched downloads, automatic retries and an optional disk cache make it practical to run over large prediction grids.

How it works

get_blues() is the first stage of a two-stage multi-environment analysis. For each environment it fits y = mu + g + b + e in ASReml. By default genotype is fixed, so it returns BLUEs rather than BLUPs and avoids double shrinkage before the genomic stage, and block is random, which works better with few blocks and recovers inter-block information. Setting genotype_random = TRUE returns BLUPs and Cullis heritability for each environment instead. Besides the long BLUE table and the wide genotype × environment matrix, it returns 1/se² weights ready for the second-stage GxE or genomic model, diagnostics for each environment (n, convergence, CV%) and the list of environments that failed to converge.

How it works

find_pivots() identifies PIVOT locations within a Target Population of Environments (TPE): the subset of trial sites that best represents the whole network, so a smaller set of locations can stand in for the full network in future testing. For each location, environmental covariates are summarised as their 10th/50th/90th percentiles and standardised into a location × covariate matrix (S). In parallel, a phenotypic kernel (K0) is built from a Gaussian kernel of per-location/year trait quantiles, capturing how similar locations are in observed performance. A PLS2 regression (plsdepot::plsreg2) relates S to K0, and a new Gaussian kernel (K) is built from the resulting PLS weights, so locations end up close in K only if they share both environmental profile and phenotypic response. Finally, STPGA::GenAlgForSubsetSelectionNoTest runs a genetic algorithm over K to pick the n_pivots locations that minimise PEVMEAN (mean prediction error variance), which is the subset that best predicts the rest of the network. Locations left out are the most environmentally/phenotypically distinct ones, not the representative ones.

Akdemir, Sánchez & Jannink (2015), Genetics Selection Evolution 47, 38 · Costa-Neto, Fritsche-Neto & Crossa (2021), Heredity 126(1), 92–105.

Model Scripts

Ready-to-run analyses from my papers. Each card writes out the models, shows the ASReml-R code for every option and links to the full script, so you can pick the structure that fits your data.

The idea

The same population is evaluated in several generations. The lines inside it are not true replicates from one generation to the next, but they share the population's genetic background, so the population effects in different generations are correlated. Modeling this covariance lets each generation borrow information from the others and makes the selection of populations more accurate. All models below share the same fixed part and differ only in the genetic matrix (G) and the residual matrix (R):

y = μ1 + X₁r + X₂b + Zg + ε

r : location and generation effects (fixed)
b : block within location (random)
g : population effect in each generation,  g ~ N(0, Σg ⊗ I)
ε : residual,  ε ~ N(0, R)
+ population × generation × location interaction (random)

a = number of generations (here F2, F3, F4: a = 3)
I = identity matrix,  J = matrix of ones,  ⊗ = Kronecker product

M1 · Identity (ID)

A main population effect plus a population-within-generation effect, each with a single variance. No generation has its own variance. The covariance it implies is the same as compound symmetry (M3), which is why both models reach the same likelihood.

Σg = σ²g J + σ²gg I

random = ~ G + Ger:G + G:Ger:L + B:L

M2 · Diagonal (DIAG)

Each generation has its own genetic variance, and generations are treated as independent: nothing is borrowed between them.

Σg = diag(σ²F2, σ²F3, σ²F4)

random = ~ at(Ger):G + G:Ger:L + B:L

M3 · Compound symmetry (CS)

The same genetic variance in every generation and the same correlation between any two generations.

Σg = σ²g [ ρJ + (1 − ρ)I ]

random = ~ corv(Ger):G + G:Ger:L + B:L

M4 · Heterogeneous compound symmetry (CSH)

One genetic variance per generation and a single genetic correlation between generations. It captures that genetic variance changes as inbreeding advances, while keeping one parameter for the link between generations.

Σg = D [ ρJ + (1 − ρ)I ] D,   D = diag(σF2, σF3, σF4)

random = ~ corh(Ger):G + G:Ger:L + B:L

M5 · Unstructured (UN)

One variance per generation and one correlation for each pair of generations. The most flexible option, but the number of parameters grows quickly with the number of generations: a(a + 1)/2.

Σg = [ σ²F2       σF2,F3    σF2,F4 ]
     [ σF3,F2     σ²F3      σF3,F4 ]
     [ σF4,F2     σF4,F3    σ²F4   ]

random = ~ corgh(Ger):G + G:Ger:L + B:L

M6 · Factor analytic (FA1)

One latent factor explains the covariance between generations (loadings λ), plus a specific variance for each generation (Ψ). Useful when there are many generations or environments. With only three generations, FA1 has as many parameters as UN and reaches the same fit.

Σg = λλ' + Ψ

random = ~ fa(Ger, 1):G + G:Ger:L + B:L

M7 · CSH for G + heterogeneous residual (selected)

The genetic structure of M4 plus one residual variance per generation. Early generations are more heterogeneous within plots, so a single residual variance is unrealistic. This was the best model in the paper by a wide margin.

Σg = D [ ρJ + (1 − ρ)I ] D
R  = σ²e,F2 I ⊕ σ²e,F3 I ⊕ σ²e,F4 I

random   = ~ corh(Ger):G + G:Ger:L + B:L,
residual = ~ dsum(~ units | Ger)

Choosing the model

All models share the same fixed part, so they can be compared by AIC and BIC from REML (lower is better). For grain yield in the paper:

model  R     G      logL      AIC      BIC
M7     DIAG  CSH    -80.48    178.96   213.15   ← selected
M4     ID    CSH   -121.19    254.39   277.18
M2     ID    DIAG  -122.86    255.72   274.71
M5     ID    UN    -121.07    258.14   288.53
M6     ID    FA1   -121.07    258.14   288.53
M1     ID    ID    -127.05    262.11   277.30
M3     ID    CS    -127.05    262.11   277.30

Table 4 of the paper. The script reproduces these log-likelihoods; the AIC and BIC printed by summary() may differ by a constant in M1–M6, depending on how the residual variance is counted, without changing the ranking.

The script also runs the single-environment analyses first (likelihood-ratio test for the population effect, heritability and accuracy), then uses the selected model to predict the population BLUPs, their accuracy (r = √(1 − PEV/σ²g)) and the expected gain from selecting the best populations.

Sousa, Vieira, Fronza, Vieira Netto, Lima, Dias & Nardino (2025), Euphytica 221, 55 · Smith, Cullis & Thompson (2001), Biometrics 57(4), 1138–1147 · Piepho, Möhring, Melchinger & Büchse (2008), Euphytica 161, 209–228.

Step 1 · FA model with one intercept per management

The genetic effects in each environment are explained by a few latent factors: environmental loadings (Λ) times genotype scores (f), plus a specific deviation (δ). Each management has its own intercept, and each environment its own residual variance.

y = μ_m + Xβ + Zg + ε
g = (Λ ⊗ I) f + δ,   δ ~ N(0, Ψ ⊗ I),   ε ~ N(0, ⊕ σ²e,j I)

Mod1 <- asreml(fixed = GY ~ - 1 + Harvest + rep:env + env,
               random = ~ gen:fa(env, 1),
               residual = ~ dsum(~id(units) | env),
               na.action = na.method(x = "include", y = "include"), maxit = 100,
               data = data)
# Mod2 to Mod5: the same model with gen:fa(env, 2) ... gen:fa(env, 5)

Step 2 · Rotation of loadings and scores

A singular value decomposition makes the factors orthogonal and orders them by importance. After rotation, factor 1 usually has mostly positive loadings and represents overall performance.

Λ = U L^(1/2) V'   →   Λ* = U,   f* = (L^(1/2) V' ⊗ I) f,   D = L

Step 3 · Choosing the FA model

The function fa.outs2(), included in the script, rotates each model and returns its diagnostics, including the average semivariance ratio (ASVR), the share of the genetic (co)variance between environments that the factors capture. You choose the model: the first one whose ASVR reaches 75% (FA4 in the paper).

ASVR = average semivariance of Λ* D Λ*'  /  average semivariance of G
G    = Λ* D Λ*' + Ψ

fa.models <- list(Mod1, Mod2, Mod3, Mod4, Mod5)
fa.res    <- lapply(fa.models, function(x) fa.outs2(x, name.env = "env",
                                                 name.gen = "gen", name.harvest = "Harvest"))
diagnos   <- do.call(rbind, lapply(fa.res, function(x) x$diagnostics))

fa4 = fa.res[[4]]      # CHOOSE: index of the chosen model

Step 4 · GIS-FA: prediction in the TPE

For each management, a PLS regression links the rotated loadings of the tested environments to their ECs. The coefficients are applied to the ECs of every pixel to predict its loadings, which are combined with the genotype scores to give the eBLUP of every genotype in every pixel. You choose the number of PLS components: in the paper it was 7, the number with the highest mean correlation between predicted and observed eBLUPs when leaving one environment out at a time.

Λ* = W B + E               # PLS
Λ*_U = Ω B̂                 # loadings of the untested pixels
g_U = (Λ*_U ⊗ I) f*        # eBLUP of every genotype in every pixel

harvest <- "seq"           # "seq" (rainfed) or "irr" (irrigated)

pls_model_all <- plsr(lambda ~ CovAmb, validation = "none",
                      data = data.pls.lamb_all,
                      ncomp = 7)          # CHOOSE the number of components
coef_pls_all  <- coef(pls_model_all, intercept = TRUE)[,,1]

pred_lambda = scale(mat_full) %*% coef_pls_all[-1, ]
# + the intercept of each factor (fa1 ... fa4)
EBLUPs_pred = pred_lambda %*% t(fa4$rot.scores) + mean(data$GY, na.rm = T)

The output is the eBLUP of every genotype in every pixel, with its coordinates, ready for which-won-where maps.

Sousa, Blasques, Condé, Silva, Eides, Fronza, Fernandes, Carneiro, Bhering, Nardino & Dias (2026), Crop Science 66, e70309 · Araújo et al. (2024), Theoretical and Applied Genetics · Smith, Norman, Kuchel & Cullis (2021), Frontiers in Plant Science 12, 737462.

Como funciona

Para cada nível do fator ambiente, a get_weights_blue() ajusta um modelo misto independente no ASReml. A resposta é modelada com efeito fixo de genótipo mais um efeito aleatório de bloco (delineamento DBC), ou de repetição e bloco incompleto dentro de repetição (delineamento látice). De cada modelo, a função extrai as BLUEs de genótipo com a matriz completa de variâncias e covariâncias das médias preditas, e calcula um peso para cada genótipo como a diagonal da inversa dessa matriz:

W = diag( solve(vcov) )

em que vcov é a matriz de variâncias e covariâncias das médias preditas de genótipo naquele ambiente. Esses pesos, junto com a variância residual do ambiente (sigma2), são exatamente o que o segundo estágio de uma análise de GxE ponderada precisa, como nos modelos fatoriais analíticos ou GIS-FA. Assim, as BLUEs estimadas com menor precisão recebem menos peso.

Smith, Cullis & Thompson (2001), Biometrics 57(4), 1138–1147 · Smith, Cullis & Gilmour (2001), Aust. N.Z. J. Stat. 43(2), 129–145 · Möhring & Piepho (2009), Crop Science 49(6), 1977–1988.

Como funciona

Para cada ambiente, a single_analysis() ajusta dois modelos mistos no ASReml, um com o efeito de genótipo aleatório e um modelo nulo sem esse efeito, e os compara com um teste de razão de verossimilhança (LRT) para verificar se o efeito de genótipo é significativo. Dos mesmos modelos, a função extrai os componentes de variância genética e residual, a herdabilidade de Cullis (baseada no erro padrão médio da diferença, avsed), a herdabilidade no sentido amplo e o coeficiente de variação (CV) residual. Ambientes em que o efeito de genótipo não é significativo (p ≥ alpha) são descartados, e os demais são renomeados em sequência (E01, E02, ...). O resultado fica pronto para os modelos multiambientais seguintes, como o fatorial analítico ou o GIS-FA, que esperam rótulos de ambiente limpos e sequenciais.

Cullis, Smith & Coombes (2006), J. Agric. Biol. Environ. Stat. 11(4), 381–393 · Piepho & Möhring (2007), Genetics 177(3), 1881–1888.

Como funciona

A rfsi_envcov() organiza a Random Forest Spatial Interpolation (RFSI) em um fluxo de trabalho completo, usando as funções rfsi() e pred.rfsi() do pacote meteo. O problema que ela resolve: as covariáveis climáticas só estão disponíveis numa grade grosseira (ex.: NASA POWER, ~50 km), enquanto as covariáveis de solo vêm de uma grade bem mais fina (ex.: SoilGrids, ~1 km), e um modelo de predição genômica precisa das duas na mesma grade. Diferente de um random forest comum, o RFSI não usa apenas as coordenadas como preditoras. Para cada ponto alvo, ele constrói variáveis a partir dos valores observados nos n vizinhos mais próximos e das distâncias até eles, o que permite ao modelo capturar diretamente a autocorrelação espacial. A ideia é parecida com a da krigagem, mas sem assumir um variograma paramétrico. Para cada variável climática, a função primeiro ajusta o número de vizinhos e de árvores por validação cruzada leave-one-out, depois retreina com todos os pontos de treino e prediz na grade fina. O resultado é uma única tabela com as variáveis de solo originais e as variáveis climáticas interpoladas.

Sekulić, Kilibarda, Heuvelink, Nikolić & Bajat (2020), Remote Sensing 12(10), 1687.

Como funciona

A get_envcov() monta a matriz de covariáveis ambientais (W) com clima, solo ou ambos para qualquer conjunto de pontos geográficos, cobrindo dois cenários. Para ambientes avaliados (experimentos reais), você informa os pontos com as datas reais de plantio e colheita de cada local, e o clima é baixado para o ciclo real. Para ambientes não avaliados (uma grade de predição), não há datas reais, então você define uma janela típica de plantio, a duração do ciclo e um intervalo de anos para tirar a média. O clima vem do NASA POWER via EnvRtype::get_weather(), com variáveis ecofisiológicas (GDD, FRUE, VPD etc.) calculadas pelo EnvRtype::processWTH() a partir das temperaturas cardinais da cultura. O solo vem de rasters do SoilGrids baixados previamente e amostrados em cada ponto com terra::extract(). Downloads em lotes, novas tentativas automáticas e um cache opcional em disco tornam viável rodar em grades de predição grandes.

Como funciona

A get_blues() é o primeiro estágio de uma análise multiambiental em dois estágios. Para cada ambiente, ela ajusta y = mu + g + b + e no ASReml. Por padrão, o genótipo é fixo, então a função devolve BLUEs, e não BLUPs, evitando o encolhimento duplo antes do estágio genômico. Já o bloco é aleatório por padrão, o que funciona melhor com poucos blocos e recupera informação interbloco. Com genotype_random = TRUE, ela devolve BLUPs e a herdabilidade de Cullis por ambiente. Além da tabela longa de BLUEs e da matriz larga genótipos × ambientes, a função devolve pesos 1/se² prontos para o modelo GxE ou genômico do segundo estágio, diagnósticos por ambiente (n, convergência, CV%) e a lista de ambientes que não convergiram.

Como funciona

A find_pivots() identifica locais PIVÔ dentro de uma População-Alvo de Ambientes (TPE, do inglês Target Population of Environments): o subconjunto de locais de ensaio que melhor representa toda a rede, de modo que um número menor de locais possa substituir a rede completa em testes futuros. Para cada local, as covariáveis ambientais são resumidas pelos percentis 10, 50 e 90 e padronizadas numa matriz local × covariável (S). Em paralelo, um kernel fenotípico (K0) é construído a partir de um kernel Gaussiano dos percentis do caráter por local/ano, capturando o quão semelhantes os locais são em desempenho observado. Uma regressão PLS2 (plsdepot::plsreg2) relaciona S a K0, e um novo kernel Gaussiano (K) é construído a partir dos pesos do PLS resultantes, de forma que os locais só ficam próximos em K se compartilharem tanto o perfil ambiental quanto a resposta fenotípica. Por fim, a STPGA::GenAlgForSubsetSelectionNoTest roda um algoritmo genético sobre K para escolher os n_pivots locais que minimizam o PEVMEAN (variância média do erro de predição), ou seja, o subconjunto que melhor prediz o restante da rede. Os locais deixados de fora são os mais distintos dos pontos de vista ambiental e fenotípico, não os mais representativos.

Akdemir, Sánchez & Jannink (2015), Genetics Selection Evolution 47, 38 · Costa-Neto, Fritsche-Neto & Crossa (2021), Heredity 126(1), 92–105.

Scripts de Modelos

Análises prontas dos meus artigos. Cada cartão escreve os modelos, mostra o código em ASReml-R de cada opção e traz o script completo, para você escolher a estrutura que se ajusta aos seus dados.

A ideia

A mesma população é avaliada em várias gerações. As linhas dentro dela não são repetições verdadeiras de uma geração para a outra, mas compartilham o mesmo fundo genético da população, então os efeitos da população em gerações diferentes são correlacionados. Modelar essa covariância permite que cada geração aproveite a informação das outras e torna a seleção das populações mais acurada. Todos os modelos abaixo têm a mesma parte fixa e diferem apenas na matriz genética (G) e na matriz residual (R):

y = μ1 + X₁r + X₂b + Zg + ε

r : efeitos de local e de geração (fixos)
b : bloco dentro de local (aleatório)
g : efeito da população em cada geração,  g ~ N(0, Σg ⊗ I)
ε : resíduo,  ε ~ N(0, R)
+ interação população × geração × local (aleatória)

a = número de gerações (aqui F2, F3, F4: a = 3)
I = matriz identidade,  J = matriz de uns,  ⊗ = produto de Kronecker

M1 · Identidade (ID)

Um efeito principal de população mais um efeito de população dentro de geração, cada um com uma única variância. Nenhuma geração tem variância própria. A covariância resultante é a mesma da simetria composta (M3), por isso os dois modelos chegam à mesma verossimilhança.

Σg = σ²g J + σ²gg I

random = ~ G + Ger:G + G:Ger:L + B:L

M2 · Diagonal (DIAG)

Cada geração tem sua própria variância genética, e as gerações são tratadas como independentes: nada é aproveitado de uma para a outra.

Σg = diag(σ²F2, σ²F3, σ²F4)

random = ~ at(Ger):G + G:Ger:L + B:L

M3 · Simetria composta (CS)

A mesma variância genética em todas as gerações e a mesma correlação entre quaisquer duas gerações.

Σg = σ²g [ ρJ + (1 − ρ)I ]

random = ~ corv(Ger):G + G:Ger:L + B:L

M4 · Simetria composta heterogênea (CSH)

Uma variância genética por geração e uma única correlação genética entre gerações. Captura que a variância genética muda com o avanço da endogamia, mantendo um só parâmetro para a ligação entre as gerações.

Σg = D [ ρJ + (1 − ρ)I ] D,   D = diag(σF2, σF3, σF4)

random = ~ corh(Ger):G + G:Ger:L + B:L

M5 · Não estruturada (UN)

Uma variância por geração e uma correlação para cada par de gerações. É a opção mais flexível, mas o número de parâmetros cresce rápido com o número de gerações: a(a + 1)/2.

Σg = [ σ²F2       σF2,F3    σF2,F4 ]
     [ σF3,F2     σ²F3      σF3,F4 ]
     [ σF4,F2     σF4,F3    σ²F4   ]

random = ~ corgh(Ger):G + G:Ger:L + B:L

M6 · Fator analítico (FA1)

Um fator latente explica a covariância entre as gerações (cargas λ), mais uma variância específica para cada geração (Ψ). É útil quando há muitas gerações ou ambientes. Com apenas três gerações, o FA1 tem tantos parâmetros quanto o UN e chega ao mesmo ajuste.

Σg = λλ' + Ψ

random = ~ fa(Ger, 1):G + G:Ger:L + B:L

M7 · CSH para G + resíduo heterogêneo (selecionado)

A estrutura genética do M4 mais uma variância residual por geração. As primeiras gerações são mais heterogêneas dentro das parcelas, então uma única variância residual não é realista. Foi o melhor modelo no artigo, com ampla vantagem.

Σg = D [ ρJ + (1 − ρ)I ] D
R  = σ²e,F2 I ⊕ σ²e,F3 I ⊕ σ²e,F4 I

random   = ~ corh(Ger):G + G:Ger:L + B:L,
residual = ~ dsum(~ units | Ger)

Escolhendo o modelo

Todos os modelos têm a mesma parte fixa, então podem ser comparados pelo AIC e pelo BIC da REML (quanto menor, melhor). Para a produtividade de grãos no artigo:

modelo R     G      logL      AIC      BIC
M7     DIAG  CSH    -80.48    178.96   213.15   ← selecionado
M4     ID    CSH   -121.19    254.39   277.18
M2     ID    DIAG  -122.86    255.72   274.71
M5     ID    UN    -121.07    258.14   288.53
M6     ID    FA1   -121.07    258.14   288.53
M1     ID    ID    -127.05    262.11   277.30
M3     ID    CS    -127.05    262.11   277.30

Tabela 4 do artigo. O script reproduz esses valores de logL; o AIC e o BIC impressos pelo summary() podem diferir por uma constante em M1–M6, conforme a contagem da variância residual, sem mudar a ordem dos modelos.

O script também faz antes as análises individuais de cada ambiente (teste da razão de verossimilhança para o efeito de população, herdabilidade e acurácia) e depois usa o modelo selecionado para predizer os BLUPs das populações, a acurácia deles (r = √(1 − PEV/σ²g)) e o ganho esperado com a seleção das melhores populações.

Passo 1 · Modelo FA com um intercepto por manejo

Os efeitos genéticos em cada ambiente são explicados por poucos fatores latentes: cargas ambientais (Λ) vezes escores dos genótipos (f), mais um desvio específico (δ). Cada manejo tem seu próprio intercepto, e cada ambiente sua própria variância residual.

y = μ_m + Xβ + Zg + ε
g = (Λ ⊗ I) f + δ,   δ ~ N(0, Ψ ⊗ I),   ε ~ N(0, ⊕ σ²e,j I)

Mod1 <- asreml(fixed = GY ~ - 1 + Harvest + rep:env + env,
               random = ~ gen:fa(env, 1),
               residual = ~ dsum(~id(units) | env),
               na.action = na.method(x = "include", y = "include"), maxit = 100,
               data = data)
# Mod2 a Mod5: o mesmo modelo com gen:fa(env, 2) ... gen:fa(env, 5)

Passo 2 · Rotação das cargas e dos escores

Uma decomposição em valores singulares torna os fatores ortogonais e os ordena por importância. Depois da rotação, o fator 1 costuma ter cargas quase todas positivas e representa o desempenho geral.

Λ = U L^(1/2) V'   →   Λ* = U,   f* = (L^(1/2) V' ⊗ I) f,   D = L

Passo 3 · Escolha do modelo FA

A função fa.outs2(), incluída no script, faz a rotação de cada modelo e retorna os diagnósticos dele, entre eles a razão média de semivariância (ASVR), que é a parcela da (co)variância genética entre ambientes captada pelos fatores. Você escolhe o modelo: o primeiro cuja ASVR chega a 75% (FA4 no artigo).

ASVR = semivariância média de Λ* D Λ*'  /  semivariância média de G
G    = Λ* D Λ*' + Ψ

fa.models <- list(Mod1, Mod2, Mod3, Mod4, Mod5)
fa.res    <- lapply(fa.models, function(x) fa.outs2(x, name.env = "env",
                                                 name.gen = "gen", name.harvest = "Harvest"))
diagnos   <- do.call(rbind, lapply(fa.res, function(x) x$diagnostics))

fa4 = fa.res[[4]]      # ESCOLHA: índice do modelo escolhido

Passo 4 · GIS-FA: predição na TPE

Para cada manejo, uma regressão PLS liga as cargas rotacionadas dos ambientes testados às suas ECs. Os coeficientes são aplicados às ECs de cada pixel para predizer as cargas dele, que são combinadas com os escores dos genótipos e dão o eBLUP de cada genótipo em cada pixel. Você escolhe o número de componentes da PLS: no artigo foram 7, o número com a maior correlação média entre os eBLUPs preditos e observados deixando um ambiente de fora por vez.

Λ* = W B + E               # PLS
Λ*_U = Ω B̂                 # cargas dos pixels não testados
g_U = (Λ*_U ⊗ I) f*        # eBLUP de cada genótipo em cada pixel

harvest <- "seq"           # "seq" (sequeiro) ou "irr" (irrigado)

pls_model_all <- plsr(lambda ~ CovAmb, validation = "none",
                      data = data.pls.lamb_all,
                      ncomp = 7)          # ESCOLHA o número de componentes
coef_pls_all  <- coef(pls_model_all, intercept = TRUE)[,,1]

pred_lambda = scale(mat_full) %*% coef_pls_all[-1, ]
# + o intercepto de cada fator (fa1 ... fa4)
EBLUPs_pred = pred_lambda %*% t(fa4$rot.scores) + mean(data$GY, na.rm = T)

O resultado é o eBLUP de cada genótipo em cada pixel, com as coordenadas, pronto para os mapas de quem ganha onde.
